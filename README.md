# PACk IA PME, landing « PME alimentaires »

Déclinaison agroalimentaire de la landing PME (artru-consulting/landing-pme). Page statique (HTML et CSS, aucun script, aucun cookie, aucun service tiers), publiable par GitHub Pages dans un nouveau dépôt, par exemple `landing-pme-alimentaire`.

## Avant de passer en ligne publique
1. Retirer `<meta name="robots" content="noindex, nofollow">` de `index.html`, `mentions-legales/index.html` et `confidentialite/index.html`.
2. Remplacer `Disallow: /` par `Allow: /` dans `robots.txt` (ou supprimer le fichier).
3. Relire les prix (repris des pages landing-ia et landing-pme), les engagements et les chiffres d'études.

## Fichiers
- `index.html` : la page. `mentions-legales/`, `confidentialite/`, `404.html`.
- `assets/` : logo, favicon, photo de Pierre, logo et certificat Qualiopi, police Atkinson Hyperlegible (licence OFL).
